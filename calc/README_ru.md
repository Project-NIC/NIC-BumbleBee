# calc/ — NIC-FPLG: эмулятор динамики и первые расчёты

*[English](README.md) · [Čeština](README_cs.md) · [Русский](README_ru.md)*

*Основной является английская версия.*

*0D-эмулятор динамики свободного поршня NIC-FPLG с минимумом зависимостей.
Он существует, чтобы дать первые числа, которых ждёт конструкция (DESIGN ch.14:
«Конкретные числа TBD — первая задача для `calc/`»).*

---

## Что это такое (и чем не является) — честно

**Это** сосредоточенная 0D-модель: одна степень свободы, камеры с идеальным газом,
идеализированный выпуск через окна и продувка (сброс давления, а не модель течения).
Это правильный инструмент для **динамики, резонанса, амплитуды, управления и
оценок первого порядка**. Каждый входной параметр — это *исходное значение*, а не результат.

**Это не** CFD (продувка/расслоение заряда — OQ-A3), не магнитная цепь
(OQ-C/FEM) и не усталостный ресурс (OQ-D). Именно здесь начинается передача
профессиональным инструментам (см. ниже).

## Запуск

```bash
pip install -r requirements.txt
python3 run.py                 # full run: report + plots + CSV in out/
python3 run.py --no-plots      # text + CSV only (no matplotlib)
python3 verify.py              # self-tests — run before trusting any number
```

Всё, что можно менять, находится в [`params.py`](params.py); у каждого поля указана
глава конструкции или открытый вопрос, из которого оно взято.

## Что говорят сегодняшние числа (главное)

**1. Частоту задаёт пружина сгорания, а не воздушная пружина.** Воздушная
пружина под поршнем сама по себе мягкая (~10 Hz при 1 kg). Доминирует жёсткость
сжатия при сгорании (растущая с давлением), поэтому предельный цикл сам выбирает
**~40 Hz** (выше первоначальной оценки 30 Hz). Следовательно, частота **не
фиксируется одной лишь геометрией** — её удерживают контуры смеси + нагрузки (ch.12,
`freq_hold.py`, `control.py`).

**2. Масса — главный рычаг — `tradeoff.py`.** f ∝ 1/√m. При фиксированной амплитуде
сила вибрации следует за силой сгорания, так что бо́льшая масса её *не* снижает
— меньшая масса лучше и для мощности, и для вибрации. Поэтому тяжёлый стальной поршень
*понижает* частоту (и число циклов → помогает ресурсу) — все ваши решения в пользу
надёжности указывают в одну сторону.

**3. Вибрация — `twin.py`.** Один модуль — ~1.4 kN; противофазная пара
гасит результирующую *силу* на ~88 %, но оставляет *опрокидывающий момент* (~165 N·m при
расстоянии 120 mm), который воспринимают опоры. Уменьшить его можно соосной установкой
модулей друг за другом.

**4. Магнитная цепь генератора (первичная оценка) — `magnetics.py`.** Оценка по сети
магнитных сопротивлений даёт ~0.9 T в воздушном зазоре, ~185 витков/фазу для шины с пиковым
напряжением 110 V и ~1.1 kN силы для 3 kW. Ключевой результат — **запас по размагничиванию
~8×** относительно коэрцитивной силы магнита в горячем состоянии: гасимое гибридное поле
выглядит геометрически реализуемым **без необратимого размагничивания, если поток
возбуждения проводится в обход магнитов** (ch.8). Это только 1D-модель магнитных
сопротивлений — окончательный вердикт по-прежнему за FEMM/Maxwell (OQ-C), но ставка
раздела C выдерживает первую проверку.

**5. Акустика выпуска / Y-эжектор — `exhaust_acoustics.py`.** При 40 Hz длина волны в
отработавших газах ~17 m, а настроенной четвертьволновой трубе потребовалось бы ~4.2 m —
невозможно в компактном двигателе. Поэтому **настроенный выпуск исключён** на этой частоте,
что подтверждает выбор открытого выпуска (ch.9): двигатель не теряет заряд в трубу, поэтому
ему не нужна настроенная камера. Y-эжектор, если он вообще помогает, — это слабая прямая
перекрёстная связь импульсов, а не резонанс; проверять его имеет смысл только
нестационарным 1D/CFD (OQ-A5).

**Здесь это не считается.** Детонация, химия горения и NOx, зазор между поршнем и цилиндром в горячем состоянии, тепловой баланс, усталость до 10⁹ циклов и путь к 50 Hz — не задачи для 0D-модели: для них нужно более серьёзное ПО — CFD с химией, Cantera, FEA — или построенный двигатель на стенде (*Передача профессиональным инструментам*, ниже).

## Насколько этому можно доверять

`verify.py` проверяет три вещи (все проходят): предельный цикл не зависит от шага;
при отключённых сгорании и демпфировании свободные колебания совпадают с аналитическим
резонансом с точностью ~1 %; энергетический баланс сходится. Он **не** гарантирует
*абсолютную* частоту — она зависит от исходных параметров сгорания, поэтому абсолютные
числа следует читать как ±несколько Hz, пока 0D/1D-цикл (OQ-A1) и прототип их не уточнят.
*Тенденции* (какой рычаг сдвигает f и насколько) надёжны.

## Передача профессиональным инструментам (= ваши OPEN-QUESTIONS)

| вопрос | инструмент |
|----------|------|
| Продувка и расслоение заряда (OQ-A3) — *ключевой, несущий вопрос* | 3D CFD с химией: Converge, AVL FIRE, STAR-CCM+ или бесплатный OpenFOAM |
| 1D-газообмен, эжектор выпуска (OQ-A2, A5) — *первичная оценка в `exhaust_acoustics.py`* | GT-Power, Ricardo WAVE, AVL BOOST |
| Магнитная цепь, размагничивание (OQ-C) — *первичная оценка в `magnetics.py`* | FEM: FEMM (бесплатный, 2D-осесимметричный — идеален для трубчатой машины), Ansys Maxwell |
| Усталость до 10⁹ циклов (OQ-D) | FEA + **пульсатор** (испытание, а не моделирование) |
| Более точная химия горения / NOx | Cantera (бесплатный, Python) — всё ещё выполнимо в 0D |
